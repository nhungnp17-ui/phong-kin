# Phòng Kín

Game giải đố – platformer đen trắng kết hợp vật lý & hoá học (HTML5 canvas, 1 file).

**Chơi ngay:** https://nhungnp17-ui.github.io/phong-kin/

Điều khiển: ←/→ (A/D) di chuyển · Space/↑ nhảy · Q lướt · E tương tác (giữ E xoay gương) · ↓ cúi · J/F ném bình, X đổi bình (chương chiến đấu) · M tắt tiếng.
